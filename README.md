# Efteling in Roblox

Realistische, op schaal gebouwde Efteling in Roblox Studio, met modellen uit Blender.

- `reference/` — plattegronden op schaal, maatvoering (CSV/JSON/OBJ), referentiefoto's en een Luau-script dat de layout als markers in Studio zet. Zie `reference/README.md`.

Schaal: 3 studs = 1 meter. Oorsprong (0,0) = midden van het park. X = oost, Z = -noord.
